ABOUT THE PROJECT

DiaRisk Analytics

An academic analytics platform combining dataset inspection, interactive visualization, machine learning evaluation, and explainable AI.

Stack

Python, Flask, Pandas, scikit-learn, XGBoost, CatBoost, Plotly, SHAP, and LIME.

Models

Logistic Regression, Decision Tree, Random Forest, SVM, XGBoost, and CatBoost.

Scope

BRFSS health indicators and lifestyle/clinical profile datasets. MongoDB history is reserved for Phase 9.

Academic context

Data Analytics and Visualization, 24DSB3101. Guide: Garimidi Siva Sree.

Model outputs support academic analysis only and must not be interpreted as medical diagnosis.
